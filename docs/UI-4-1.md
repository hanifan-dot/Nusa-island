- **Label nama/gelar** (`world/look.js`): dua baris (gelar kecil di atas, nama tebal di bawah), latar transparan lembut, lebar maks 96 px dengan "…", berhenti ≥3 px di atas kepala. Berlaku untuk karakter sendiri dan pemain lain.
- **Chat** (`mp/ui.js`, `mp/mp.css`, `mp/client.js`): 💬 membuka panel kaca semi-transparan di kiri atas (di luar jangkauan keyboard & joystick) berisi riwayat (nama berwarna), kolom ketik, Kirim, emoji cepat; lencana belum dibaca = pesan nyata dari pemain lain. Bubble di atas label, maks 3 baris × 20 huruf + "…" (lengkap di panel), mengikuti karakter, hilang otomatis, tidak keluar layar, tidak saling menimpa. Keyboard Android: `interactive-widget=overlays-content`, kanvas tidak ditata ulang saat mengetik, dirapikan sekali setelah keyboard menutup; teks petunjuk tengah disembunyikan saat menu/chat terbuka. Filter, rate limit, dan server multiplayer tidak diubah.
